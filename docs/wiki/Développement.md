# Développement

Architecture, tests, compilation de l'exécutable et ajout d'un type de contenu : voir [docs/DEVELOPPEMENT.md](https://github.com/molotovah/Forge411/blob/main/docs/DEVELOPPEMENT.md) dans le dépôt.

## Ce wiki

Les pages sont dans [`docs/wiki/`](https://github.com/molotovah/Forge411/tree/main/docs/wiki) du dépôt. Le workflow « Wiki » les publie ici à chaque modification sur `main` : toute modification faite directement sur le wiki serait écrasée. Pour corriger une page, ouvre une pull request.

Les captures d'écran viennent de `docs/screenshots/`. Le workflow « Captures du README » régénère une partie d'entre elles à chaque version, avec des données de démonstration.

## Signaler un problème

Ouvre une [issue](https://github.com/molotovah/Forge411/issues) en joignant le journal `forge411.log` (voir [Questions fréquentes](<Questions-fréquentes>)).
